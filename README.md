# AcmePlexus media

Public copies of finished social posts, so the scheduler can fetch them by address. Served at https://acmeplexus.github.io/acmeplexus-media/.

- Files live under `<brand>/<yyyy>/<mm>/<dd>/`.
- Only finished posts that are about to go out are put here. This repository is public.
- New files arrive on `claude/...` branches. The Intake workflow accepts only new media files in those folders, merges them into `main` and starts Publish.
